# Temporary Roadmatics Chat artwork

The RC monogram is a neutral temporary placeholder, not approved company artwork.
The SVG paths are the editable source. The purple value follows the existing
upstream primary colour; no broader theme redesign is intended.

Run `scripts/generate-roadmatics-icons.sh` with Flutter/Dart and ImageMagick in
PATH to regenerate the Android/iOS icons, notification glyphs and splash images.
Replace these SVGs with approved artwork before store publication. Historical
FluffyChat assets remain for attribution/history, but mobile UI and launch assets
use the RC files.
